# ADR-004: ライセンス・NOTICE・SBOM

- ステータス: **Draft（法務レビュー待ち）**
- 決定日: 2026-08-05
- 対象: 配布・供給網管理

## 背景

ルートLICENSEがなく、利用・改変・配布条件が不明確。OSS依存のライセンス告知も未整備だった。

## 判断（前提・法務レビュー後に確定）

1. **本ソフトウェアは社内利用を目的としたプロプライエタリ**とし、`LICENSE` に
   「社内利用限定・無断再配布禁止」を明記する（外部公開・商用利用は法務判断を仰ぐ）。
2. **OSS依存は各ライセンスを尊重**し、`THIRD_PARTY_NOTICES.md` に集約する。
3. **SBOM（CycloneDX）を生成**し、リリース資産に添付する。
   - バックエンド: `pip-licenses --format=json`
   - フロントエンド: `license-checker --json`
   - `scripts/sbom.sh` で両者をマージし `SBOM.cyclonedx.json` を生成
4. CIのリリース系ジョブでSBOM生成を実行する（本ブランチではスクリプトとドキュメントを整備）。

## 結果

- 利用条件・OSS告知の曖昧さがなくなり、監査・調達説明が可能になる。
- 依存の更新時はSBOM・NOTICEの再生成が必要になる。
- 最終的なライセンス文言は法務部門のレビューを必須とする。
